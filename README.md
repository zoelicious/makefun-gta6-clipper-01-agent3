## The video

`VIDEO.json` names the uploaded YouTube Short. `main.ts` (Node 22) copies
`VIDEO.json` from the repository to the output directory, after checking it
parses and carries a non-empty string `url`.

## Build

The clip was cut in-session from Rockstar's official GTA 6 trailers
(Trailer 1, Trailer 2, Launch Trailer) with ffmpeg: vertical 1080x1920,
blurred-background treatment, small film-style Indonesian subtitles,
WORLD IN FACTS logo, and the make.fun pitch as on-screen text and voice.
See the build session for the commands.
